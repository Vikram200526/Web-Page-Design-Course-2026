1. What broke when you moved files, and how did you find it?
- When I moved a file, if that file had relative links they would all break, and other files linking to this file would also have their links break regardless if their link was relative or root relative.

2. When did you choose relative vs. root-relative paths, and why?
- Use relative links for files in the same or close parent to the current file for quick coding, and use root relative links for files in far places and/or to prevent breaking links connecting to other files when moving the current file to a different place.

3. What is one risk of displaying an image from someone else's server?
- The image may fail to load or take a long time to load depending on the network connection which can provide a bad user experience.
